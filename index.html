How CampusGPT Works

CampusGPT is a hyper-localised AI student hub built for any Nigerian university. It uses Google's Gemma 4 as a smart router — not as a calculator — ensuring factual accuracy through programmatic tools while leveraging Gemma's language intelligence for intent detection, natural conversation, and contextual responses.

Architecture

Programmatic Tools (Gemma Routes to These)

📊

GPA Calculator Tool

When a GPA-related question is detected, Gemma routes to a deterministic JS calculator using the official Nigerian 5.0 CGPA scale. The number is always computed by code — never by the model — eliminating hallucination in math.

📍

Campus Location Tool

Location queries trigger a lookup against a seeded database of campus venues per university. Gemma then generates natural-language directions from the structured data returned by the tool.

⚠️

Exam Timeline Tool

Exam schedule data (including crowdsourced updates) is computed programmatically — days remaining, urgency levels, department filtering — before being surfaced to the user. No model guesses are involved in dates.

Gemma Integration

Every chat message goes to Gemma 4 (gemma-4-26b-a4b-it) via the Google Generative Language API. Gemma first classifies intent, then either routes to a tool or responds conversationally. It understands Pidgin English and Nigerian campus slang natively.

⚠️ Demo note: The API key is stored client-side for this prototype. In production, this call would be proxied through a serverless backend to avoid key exposure.

Data & Scale

Location and exam data for this demo is seeded JSON representing 10 Nigerian universities. The crowdsourcing layer (class rep updates) writes to localStorage and would sync to a real shared database (Firebase or Supabase) in production.

🔬 How this scales: A production version would replace seeded JSON with a Supabase database, add photo-to-text OCR for physical notice boards, and push real-time exam alerts via push notifications to enrolled students.
